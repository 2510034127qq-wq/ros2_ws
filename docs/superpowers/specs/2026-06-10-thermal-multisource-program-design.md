# 动态多热源贝叶斯搜索与持续监视 — 总体架构设计

日期：2026-06-10（2026-06-12 修订：吸收阶段 0 全量矩阵实测数据与外部评审反馈，修订内容见 §9）
状态：已与项目负责人逐节确认；2026-06-12 修订版待负责人审查
范围：总体设计（program-level）。每个阶段另有独立的 spec → plan → 实现循环，本文档是它们的共同基准。

## 1. 背景与动机

当前算法栈（controller v31）由信息增益启发式打分、最近邻源跟踪、梯度上升 + Lévy flight 组成，工程整合扎实但各组件均为已有技术，且打分权重为手调常数，每适配一个新场景就需再调一组系数。最新基准（2026-05-02 devlog）：2 源 recall 2/2，4 源 3/4，5 源在 2/5–3/5 间波动，存在明显的单次运行随机性。

本计划将探索逻辑整体重构为概率主线，利用本项目独有的结构性优势——**目标可表示为少数高斯源的地平面叠加图，且观测是整幅图像足迹而非点式测量**（气体/化学源定位文献几乎全部假设点传感器）。注意这是信念表示而非物理场声明，见 §3 两层表示声明。

## 2. 目标与成功标准

**最终目的偏向实机落地（宇树 G1），以论文级的严谨性和创新性为质量标准。**

总体成功标准（最终验收门槛）：

1. 在扩展后的多世界矩阵（含障碍、动态源、2–5 源及生灭源）上，多 seed 统计下 recall 显著优于冻结的 v31 锚点和纯 frontier / 纯 Lévy 基线（Mann-Whitney U，p<0.05）；
2. 确认质量以统计口径验收：precision 的 95% 置信下界 ≥ 0.90（口径见 §5.4：矩阵层面事件汇总 + run 级 cluster bootstrap），duplicate rate（重复确认数 / 真值源数）显著低于 v31 锚点（阶段 0 实测：v31 在动态 4 源上 8/20 局出现重复确认）。不要求逐局 precision=1.0 / duplicate=0——硬性零容忍会逼出超保守确认阈值反噬 recall；
3. 输出可校准的清场概率：可靠性曲线上宣称置信度与实际漏源率一致，期望校准误差（ECE）≤ 0.10。清场概率必须来自显式生成式模型（见 §3），不得以残差启发式分数冒充概率；
4. 信念层 + 规划层每决策周期 CPU 耗时满足算力预算（单核 ≤ 100 ms/周期，为板载部署预留）。

本轮范围**包含障碍物**（遮挡 + 可达性）。实机落地不再只是"预留接口"，而是贯穿各阶段的 sim-to-real 主线（见 §4「硬件与 sim-to-real 主线」）：阶段 1 落实透视兼容的观测接口契约与热相机选型文档，阶段 2–3 建设仿真 B 级前视传感器模型（三维热表面物体），真实热相机录包回放（C 级）在硬件到位后插入，G1 SDK 运动接口集成收尾。当前硬件现状：G1 与热相机均未到位，故 C 级及之后里程碑只定义触发条件、不进排期。

## 3. 终态架构

创新集中在信念层和规划层，执行层基本不动：

```
观测层  thermal image + /map(SLAM) + pose                      10 Hz
        ├─ visibility.py [新]     射线检测 → FOV 内每格: 可见/被遮挡
        └─ WorldThermalGrid [改]  只融合可见格; 每格三态:
                                   没看过 / 看过但被挡 / 看过且看清
                ↓
信念层  对"源集合"的估计, 快慢双层:                            1–2 Hz / 0.5–1 Hz
        ├─ 快层: source_tracking.py [改] 常速 Kalman track [x,y,vx,vy]
        │        + residual.py [新] 已知源正向预测场 − 实测场 = 残差场
        └─ 慢层: belief.py [新] 候选方案制(默认 Rao-Blackwell 源簇,
                 备选变维粒子滤波): 估计 p(N, {x,y,A,σ,vx,vy} | 观测),
                 负责源数推断、清场先验校正; 超时/降级不影响主回路
                ↓
规划层  planning.py [重写打分核] + revisit.py [新]              按需
        ├─ 探索目标: 残差质量(慢层就绪后=期望熵降) + 可见性感知未见度,
        │            候选点过可达性检查 (Nav2 costmap, 降级为直线无碰检查)
        ├─ 重访调度: stale/预测源队列, 优先级 = 预测不确定度 × 源价值
        └─ clearance.py [新]: P(存在幅值≥A_min 的未发现源) < ε → DONE
                ↓
执行层  controller_node FSM [基本不动]
        FINE 梯度上升原样保留; COARSE 目标来源换为上述规划层;
        Nav2 优先 + 直接 /cmd_vel 兜底机制不变
```

关键设计决定：

- **遮挡是观测层属性，不是规划层补丁。** 可见性掩码在图像融合时计算（用 SLAM 占据栅格从机器人位置向 FOV 足迹内每格做射线检测）。残差、信息增益、清场概率天然继承正确语义："看过但被挡"自动成为继续探索的理由，无需额外启发式。
- **两层表示声明：观测是表面辐射采样，信念是地平面源地图。** 真实热相机在长波红外波段看不到空气温度，只能看到视线内表面的辐射——"环境热场"并非实机可观测对象。因此源地图 (x,y,A,σ) 定义为信念表示（源质心的地面投影 + 强度 + 空间范围），不是物理场声明；A 级仿真的"地面温度场"是该表示在理想俯视传感器下的退化情形。实机化打破的只是观测前端（热像素分割 → 方向 + 表面温度 → 深度配准/三角化定位），信念层、规划层、FSM 均不依赖"场"假设。
- **快慢双层信念，而非慢层接管。** 快层（Kalman + 残差）毫秒级、永远在线；慢层（候选方案制，见阶段 3）可降级、可关闭。与现有"Nav2 优先、/cmd_vel 兜底"同一设计哲学，是受限算力下分层贝叶斯源搜索的创新框架，也是实机可部署的前提。
- **清场概率必须是概率，不是命名为概率的分数。** 显式生成式模型：未发现源的空间先验（自由空间上的 Poisson 强度 λ）× 幅值先验（可探测性 vs 距离/FOV）× 给定每格可见性历史的漏检似然，三者推出 P(存在幅值≥A_min 的未发现源)。验收看校准（可靠性曲线 + ECE），不看阈值是否"看起来合理"。残差版 v1 允许在漏检似然上用残差证据近似，但模型结构从阶段 1 起就按此定义。
- **观测接口契约。** 每条观测 =（射线/单元，温度测量，置信度，timestamp，frame_id，传感器位姿/外参，measurement_type ∈ {直读场温, 表面辐射}）。后四个字段是前视相机、录包回放与运动三角化的硬需求，从首个实现起就进契约，不留"以后再加"。现 `project_pixels_to_world()` 假设俯视矩形足迹（仿真特化）；阶段 1 重构为该契约的可替换实现，俯视矩形与前视透视视锥都是它的实例，算法只消费 `WorldThermalGrid`。可见性历史同时记录观测方位扇区（每格被从哪些方向看过），为视角依赖的清场模型（v2）预留数据结构，当期不增加算法复杂度。
- **所有新模块为纯 Python、无 ROS 依赖**，放入现有包（`visibility.py`、`residual.py` → thermal_field_reconstructor；`belief.py`、`revisit.py`、`clearance.py` → thermal_motion_controller），由现有 pytest 框架直接覆盖；ROS 节点只做接线。
- **频率解耦。** 观测层 10 Hz；快层 1–2 Hz；慢层 0.5–1 Hz（降采样足迹算 likelihood）；规划层在 COARSE 状态切换时按需调用。现有 `snapshot()` 接口天然支持。

## 4. 阶段划分与验收门槛

每阶段以 devlog + 提交 + 负责人审查门槛数据收尾。障碍物从阶段 0 进评测矩阵、从阶段 1 进观测模型。算力预算从阶段 1 起为贯穿性门槛。

### 阶段 0：评测地基（约 2–3 周）

- 矩阵 runner 加 `--seed/--repeats`，输出均值±标准差；
- 归因仪表（见 §5.3）；
- 带障碍评测世界（稀疏箱体、隔墙/走廊）+ Gazebo world 与真值占据栅格成对生成 + Nav2 健康检查；
- 基线挂架：`strategy` 参数可切换 v31（冻结锚点）/ frontier / levy。

**门槛**：扩展矩阵多 seed 指标可复现；基线全部跑通；每局自动生成归因报告。

**状态：已完成并通过门槛评审（2026-06-12）。** 交付 f533f1b + a936256，全量矩阵 120/120 局出数（24 用例 × 5 seed，5.35 h，devlog 2026-06-12-0141）。关键实测结论已反哺本 spec：① 漏检源归因 100% 为"没走到"——186/186 个漏检源从未进入 FOV，最近接近距离中位数 5.8 m，覆盖是唯一瓶颈，直接支撑阶段 1 优先级；② 动态 4 源场景 8/20 局出现重复确认（precision 0.75）——支撑阶段 2 必要性与 §2 验收口径修订；③ mixed 世界 Nav2 无 /plan 事件（§6 风险 1 实测证据）。

### 阶段 1：遮挡感知观测 + 残差探索 + 终止判据 v1（约 3 周）

- `visibility.py` 射线检测掩码；`WorldThermalGrid` 三态融合（每格附观测方位扇区记录）；
- 观测接口按 §3 契约抽象（射线/单元 + 温度 + 置信度），俯视矩形为首个实现；占据栅格几何常数（中心/尺寸/分辨率）统一到单一来源（现 `world_occupancy.py` 与 `WorldThermalGrid` 各持一份，运行时可见性掩码上线前必须收敛，否则离线真值栅格与在线信念栅格会静默漂移）；
- `residual.py` 残差场；`planning.py` 打分核重写（残差质量 + 可见性感知未见度 + 可达性检查）;
- `clearance.py` 清场概率 v1：按 §3 生成式模型结构实现，漏检似然允许用残差证据近似；
- `matrix_stats` 补配对检验（Wilcoxon signed-rank / 配对 permutation）与 run 级 cluster bootstrap 置信区间（§5.4 口径），供本阶段及之后所有门槛使用；
- 热相机选型文档（分辨率/帧率/接口/ROS 2 驱动/价格对比），使采购可随时触发。

**门槛**：4/5 源场景（含障碍世界）多 seed recall 显著高于 v31（配对检验）；precision 95% 置信下界 ≥ 0.90 且 duplicate rate 不高于 v31（§5.4 口径）；归因报告显示"没走到"类失败显著减少；算力预算达标。

### 阶段 2：动态源跟踪 + 重访调度（约 2–3 周）

- track 升级为常速 Kalman（[x,y,vx,vy]），stale 源重访点用预测位置；
- `revisit.py` 重访队列（优先级 = 预测不确定度 × 源价值）接入 COARSE 目标仲裁。

**门槛**：动态源场景重捕获时间与跟踪连续性可测且改善；动态矩阵 recall 提升；静态场景无回退；算力预算达标。

### 阶段 3：慢层信念（候选方案制，约 4–6 周，双重止损门）

**地位声明：阶段 1+2 完成即构成完整可发表的工作**（可见性感知观测 + 残差探索 + 运动跟踪去重 + 可校准清场）。阶段 3 是增量贡献而非依赖项——阶段 0 实测瓶颈（100% not_reached）由阶段 1/2 解决，慢层解决的是源数推断与清场概率的原则性，是全计划中技术风险最高、主线依赖最低的部分。

候选方案（按风险从低到高，进入实现前由负责人选定主攻）：

- **候选 1（默认）：Rao-Blackwell 化源簇**——每源一个 Kalman 簇（[x,y,vx,vy] 解析滤波，A/σ 条件线性估计），源数生灭由残差证据驱动（残差场持续峰 → birth 提议；长期无观测支持 → death）。簇承载标签，显著降低 label switching 风险——但源靠近、交叉、合并/拆分时仍存在数据关联问题，需配套显式 merge/split/association 规则；算力可控。
- **候选 2：变维粒子滤波**——p(N, {x,y,A,σ,vx,vy})，需设计生灭/合并/拆分跳转移动 + 带可见性掩码的图像足迹 likelihood。仅当候选 1 在源数推断上表现不足时启用。**击杀条件**：实现启动 2 周内，合成数据上源数后验不收敛、或单核预算内有效粒子数持续退化，即放弃候选 2 回到候选 1。
- **影子模式（≥2 周）**：选定方案只估计不决策，与快层在矩阵上并跑。
  **门槛 A**：源数估计准确率与定位误差全面优于快层。不过门槛 A 即停：快层系统为最终方案，对比分析进论文。
- **慢层上线**：期望信息增益进入打分核，后验版清场概率替换 v1，慢层向快层提供先验校正。
  **门槛 B**：双层系统多 seed 指标不低于纯快层，且在最难场景（5 源动态 + 障碍）显著更好；慢层降级/关闭时系统无故障退回快层行为；算力预算达标。

### 阶段 4：论文级实验（约 2–3 周）

- 全基线对比（frontier / Lévy / v31 / 快层系统 / 双层系统），另加一个文献级强基线：**GP-UCB / active-mapping 类**（GP 场信念 + UCB/信息增益选点），避免"只打弱基线"的审稿质疑。复用 strategy 挂架与同一矩阵 seed；实现工作量约 1 周，可在阶段 3 影子期并行完成；
- 消融（去可见性、去残差、去重访各跑全矩阵）；
- 清场概率校准曲线（可靠性曲线 + ECE）；统计显著性检验；
- 传感器退化敏感性实验（B 级模型上：噪声/偏置漂移/emissivity 扰动逐级加重，看各系统退化曲线），支撑 sim-to-real 主张。

**门槛**：达到 §2 总体成功标准。

### 硬件与 sim-to-real 主线（与各阶段并行）

仿真保真度阶梯：

- **A 级（现状）**：理想俯视足迹直读地面场，算法开发用。
- **B 级（阶段 2–3 期间建设）**：场景内放置三维热表面物体（盒体/柱体，指定面发热），渲染前视透视热图，叠加噪声/偏置漂移/emissivity 扰动；观测前端从热像素提取检测（方向 + 表面温度），位置由深度配准或运动三角化得到。用于验证视角依赖与自遮挡下的算法退化，产出阶段 4 的传感器退化敏感性实验。
- **C 级（硬件到位后插入，不进当前排期）**：真实热相机录包离线回放整条管线（预处理 → 重建 → 跟踪在真实帧上验证）。触发条件：热相机采购完成（选型文档为阶段 1 交付物）。
- **G1 集成（收尾）**：Unitree SDK 运动接口替换 diff-drive `/cmd_vel`、步态扰动下的观测质量、板载算力部署。明示差距：当前控制器不得新增绑死 diff-drive 假设的逻辑。

B 级实测若揭示视角依赖显著（同一位置不同朝向的探测率差异大），清场模型升级为"位置 × 观测扇区"覆盖（阶段 1 已预留方位扇区数据结构），作为 v2 决策点。

合计约 15–21 周（含 B 级传感器模型建设约 2–3 周）。风险释放点：阶段 1 门槛验证残差思路有效性；阶段 3 门槛 A 决定原则性路线或工程路线收尾（两条路都有完整交付物）；B 级模型验证视角依赖假设与表示层声明。

## 5. 评测体系（阶段 0 交付物）

### 5.1 场景矩阵

世界 × 源配置正交组合：

- **世界**（4 类）：开阔（现有）、稀疏箱体（5–8 箱，局部遮挡）、隔墙/走廊（2–3 墙，大面积遮挡 + 绕行）、混合。障碍世界同时生成 Gazebo world 与真值占据栅格。
- **源配置**（6 类）：静态 2/3/5 源、动态混合 4 源、zigzag 动态 5 源、生灭源（中途出现/熄灭，考终止与重访）。
- 每格 **5 个固定 seed**（控制传感噪声、Lévy 序列、random_walk 轨迹、源参数扰动）。

全矩阵约 120 局 × 120–180 s。runner 支持 `--worlds/--cases/--seeds` 子集筛选：日常迭代跑子集，阶段门槛跑全量（可借 `--domain-start` 并行 2–3 个无头实例）。

### 5.2 基线挂架

控制器 `strategy` 参数切换 v31 / frontier / levy / 各阶段系统 / gp_ucb（阶段 4 前补入，见 §4）；所有策略跑完全相同的矩阵与 seed。

### 5.3 归因仪表

仿真侧有上帝视角（scenario 真值 + 真值占据栅格），每个真值源每局记录：是否进过 FOV、最小 FOV 距离、无遮挡可见时间窗（含信号强度）、被遮挡接近事件数、活跃期与可见窗重叠率（动态源）、tracker 状态轨迹（首检出 → confirm 延迟，或卡点）。

每局输出失败归因摘要，漏源自动分类为：**没走到 / 被挡住 / 到了没确认 / 时机错过**。矩阵层面汇总四类占比变化，作为各阶段门槛"X 类失败减少"的数据来源。

（运行时算法用的可见性掩码与归因仪表共用同一射线检测机制：前者不见真值、后者对照真值。）

### 5.4 指标与统计

- 核心：recall / precision / duplicate（沿用现有定义，验收口径按 §2：precision 置信下界 + duplicate rate 上界，非逐局硬指标）；新增首确认时间、全源确认时间、动态源重捕获时间、清场概率校准（可靠性曲线 + ECE）、决策周期 CPU 耗时分布。
- 统计：每格 5 seed 报均值±标准差。所有策略跑完全相同的 world/case/seed，故主检验用**配对方法**（按 case+seed 配对的 Wilcoxon signed-rank 或配对 permutation/bootstrap，p<0.05）；Mann-Whitney U 降为辅助（非配对场景或稳健性复核）。阶段 0 的 `matrix_stats` 目前只实现了 MWU，配对检验在阶段 1 补入。
- 置信区间口径（precision / duplicate rate 验收防扯皮）：在矩阵层面按**确认事件汇总**计算（总正确确认数 / 总确认数），不是逐局 precision 求平均；95% CI 用以 **run 为重抽样单位**的 cluster bootstrap（≥10000 次有放回重抽样），保留 run 内确认事件的相关性。门槛比较一律以该口径为准。
- 回归保护：宣称改进必须附全矩阵成绩，局部变好、其它变差不过门槛。
- 产物：每局一个 artifact 目录（CSV + 归因 JSON + 元数据），矩阵汇总 Markdown 报告，可直接进 devlog。

## 6. 风险与回退

1. **Nav2 在障碍世界不稳**（交接报告 §14.1 的已知问题会被放大）：阶段 0 扩展 `nav2_health_check.py` 验证；评测记录每局 Nav2 可用率；可达性检查可降级为直线无碰检查；直接 `/cmd_vel` 兜底保证实验不死。
2. **慢层影子模式输给快层**：快层系统即完整交付物，慢层对比分析进论文，无沉没成本；候选 2（变维 PF）另设 2 周击杀条件（见阶段 3）。
3. **算力超预算**：慢层降复杂度（候选 2 降粒子数）/ 降频 / likelihood 降采样三档退；分层结构保证慢层降级不伤主回路。
4. **仿真吞吐瓶颈**：子集迭代 + 门槛全量 + domain 隔离并行。
5. **为单一世界调常数的故态复萌**：新常数进 `params.yaml` 必须附跨世界矩阵数据；归因仪表使修哪一层有据可查。
6. **B 级传感器模型揭示视角依赖显著、地平面源地图表示退化**：表示层已声明为信念表示而非物理声明（§3），观测前端可替换；清场模型有"位置 × 观测扇区"升级路径，数据结构阶段 1 已预留。
7. **硬件长期不到位**：C 级与 G1 集成不阻塞主线；论文叙事以 A/B 级仿真 + 退化敏感性实验支撑 sim-to-real 主张，并明示真实表面辐射效应（emissivity、反射、标定误差）为 B 级模型未完全覆盖的残余差距。

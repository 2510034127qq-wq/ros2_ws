# 动态多热源贝叶斯搜索与持续监视 — 总体架构设计

日期：2026-06-10
状态：已与项目负责人逐节确认
范围：总体设计（program-level）。每个阶段另有独立的 spec → plan → 实现循环，本文档是它们的共同基准。

## 1. 背景与动机

当前算法栈（controller v31）由信息增益启发式打分、最近邻源跟踪、梯度上升 + Lévy flight 组成，工程整合扎实但各组件均为已有技术，且打分权重为手调常数，每适配一个新场景就需再调一组系数。最新基准（2026-05-02 devlog）：2 源 recall 2/2，4 源 3/4，5 源在 2/5–3/5 间波动，存在明显的单次运行随机性。

本计划将探索逻辑整体重构为概率主线，利用本项目独有的结构性优势——**热场是少数高斯源的叠加，且观测是整幅图像足迹而非点式测量**（气体/化学源定位文献几乎全部假设点传感器）。

## 2. 目标与成功标准

**最终目的偏向实机落地（宇树 G1），以论文级的严谨性和创新性为质量标准。**

总体成功标准（最终验收门槛）：

1. 在扩展后的多世界矩阵（含障碍、动态源、2–5 源及生灭源）上，多 seed 统计下 recall 显著优于冻结的 v31 锚点和纯 frontier / 纯 Lévy 基线（Mann-Whitney U，p<0.05）；
2. precision 保持 1.0，duplicate 保持 0；
3. 输出可信的清场概率（校准曲线验证：宣称的清场置信度与实际漏源率一致）；
4. 信念层 + 规划层每决策周期 CPU 耗时满足算力预算（单核 ≤ 100 ms/周期，为板载部署预留）。

本轮范围**包含障碍物**（遮挡 + 可达性），不包含真实热相机模型和 G1 SDK 接入（仅预留接口）。

## 3. 终态架构

创新集中在信念层和规划层，执行层基本不动：

```
观测层  thermal image + /map(SLAM) + pose                      10 Hz
        ├─ visibility.py [新]     射线检测 → FOV 内每格: 可见/被遮挡
        └─ WorldThermalGrid [改]  只融合可见格; 每格三态:
                                   没看过 / 看过但被挡 / 看过且看清
                ↓
信念层  对"源集合"的估计, 快慢双层:                            1–2 Hz / 0.5–1 Hz
        ├─ 快层: source_tracking.py [改] 常速 Kalman track [x,y,vx,vy]
        │        + residual.py [新] 已知源正向预测场 − 实测场 = 残差场
        └─ 慢层: belief.py [新] 变维粒子滤波
                 p(N, {x,y,A,σ,vx,vy} | 观测), 负责源数推断、
                 清场概率、给快层提供先验校正; 超时/降级不影响主回路
                ↓
规划层  planning.py [重写打分核] + revisit.py [新]              按需
        ├─ 探索目标: 残差质量(慢层就绪后=期望熵降) + 可见性感知未见度,
        │            候选点过可达性检查 (Nav2 costmap, 降级为直线无碰检查)
        ├─ 重访调度: stale/预测源队列, 优先级 = 预测不确定度 × 源价值
        └─ clearance.py [新]: P(存在幅值≥A_min 的未发现源) < ε → DONE
                ↓
执行层  controller_node FSM [基本不动]
        FINE 梯度上升原样保留; COARSE 目标来源换为上述规划层;
        Nav2 优先 + 直接 /cmd_vel 兜底机制不变
```

关键设计决定：

- **遮挡是观测层属性，不是规划层补丁。** 可见性掩码在图像融合时计算（用 SLAM 占据栅格从机器人位置向 FOV 足迹内每格做射线检测）。残差、信息增益、清场概率天然继承正确语义："看过但被挡"自动成为继续探索的理由，无需额外启发式。
- **快慢双层信念，而非粒子滤波接管。** 快层（Kalman + 残差）毫秒级、永远在线；慢层（粒子滤波）可降级、可关闭。与现有"Nav2 优先、/cmd_vel 兜底"同一设计哲学，是受限算力下分层贝叶斯源搜索的创新框架，也是实机可部署的前提。
- **观测投影可替换。** 现 `project_pixels_to_world()` 假设俯视矩形足迹（仿真特化）；阶段 1 重构为可替换接口，算法只消费 `WorldThermalGrid`。接 G1 真实热相机（透视锥 + 俯仰角）时只换投影模块。
- **所有新模块为纯 Python、无 ROS 依赖**，放入现有包（`visibility.py`、`residual.py` → thermal_field_reconstructor；`belief.py`、`revisit.py`、`clearance.py` → thermal_motion_controller），由现有 pytest 框架直接覆盖；ROS 节点只做接线。
- **频率解耦。** 观测层 10 Hz；快层 1–2 Hz；慢层 0.5–1 Hz（降采样足迹算 likelihood）；规划层在 COARSE 状态切换时按需调用。现有 `snapshot()` 接口天然支持。

## 4. 阶段划分与验收门槛

每阶段以 devlog + 提交 + 负责人审查门槛数据收尾。障碍物从阶段 0 进评测矩阵、从阶段 1 进观测模型。算力预算从阶段 1 起为贯穿性门槛。

### 阶段 0：评测地基（约 2–3 周）

- 矩阵 runner 加 `--seed/--repeats`，输出均值±标准差；
- 归因仪表（见 §5.3）；
- 带障碍评测世界（稀疏箱体、隔墙/走廊）+ Gazebo world 与真值占据栅格成对生成 + Nav2 健康检查；
- 基线挂架：`strategy` 参数可切换 v31（冻结锚点）/ frontier / levy。

**门槛**：扩展矩阵多 seed 指标可复现；基线全部跑通；每局自动生成归因报告。

### 阶段 1：遮挡感知观测 + 残差探索 + 终止判据 v1（约 3 周）

- `visibility.py` 射线检测掩码；`WorldThermalGrid` 三态融合；投影接口抽象；
- `residual.py` 残差场；`planning.py` 打分核重写（残差质量 + 可见性感知未见度 + 可达性检查）;
- `clearance.py` 残差版清场概率。

**门槛**：4/5 源场景（含障碍世界）多 seed recall 显著高于 v31；precision 1.0、duplicate 0；归因报告显示"没走到"类失败显著减少；算力预算达标。

### 阶段 2：动态源跟踪 + 重访调度（约 2–3 周）

- track 升级为常速 Kalman（[x,y,vx,vy]），stale 源重访点用预测位置；
- `revisit.py` 重访队列（优先级 = 预测不确定度 × 源价值）接入 COARSE 目标仲裁。

**门槛**：动态源场景重捕获时间与跟踪连续性可测且改善；动态矩阵 recall 提升；静态场景无回退；算力预算达标。

### 阶段 3：变维粒子滤波慢层（约 4–6 周，双重止损门）

- `belief.py`：每源粒子 [x,y,A,σ,vx,vy]，生灭跳转，带可见性掩码的图像足迹 likelihood；
- **影子模式（≥2 周）**：只估计不决策，与快层在矩阵上并跑。
  **门槛 A**：源数估计准确率与定位误差全面优于快层。不过门槛 A 即停：快层系统为最终方案，对比分析进论文。
- **慢层上线**：期望信息增益进入打分核，后验版清场概率替换 v1，慢层向快层提供先验校正。
  **门槛 B**：双层系统多 seed 指标不低于纯快层，且在最难场景（5 源动态 + 障碍）显著更好；慢层降级/关闭时系统无故障退回快层行为；算力预算达标。

### 阶段 4：论文级实验（约 2–3 周）

- 全基线对比（frontier / Lévy / v31 / 快层系统 / 双层系统）；
- 消融（去可见性、去残差、去重访各跑全矩阵）；
- 清场概率校准曲线；统计显著性检验。

**门槛**：达到 §2 总体成功标准。

合计约 13–18 周。风险释放点：阶段 1 门槛验证残差思路有效性；阶段 3 门槛 A 决定原则性路线或工程路线收尾（两条路都有完整交付物）。

## 5. 评测体系（阶段 0 交付物）

### 5.1 场景矩阵

世界 × 源配置正交组合：

- **世界**（4 类）：开阔（现有）、稀疏箱体（5–8 箱，局部遮挡）、隔墙/走廊（2–3 墙，大面积遮挡 + 绕行）、混合。障碍世界同时生成 Gazebo world 与真值占据栅格。
- **源配置**（6 类）：静态 2/3/5 源、动态混合 4 源、zigzag 动态 5 源、生灭源（中途出现/熄灭，考终止与重访）。
- 每格 **5 个固定 seed**（控制传感噪声、Lévy 序列、random_walk 轨迹、源参数扰动）。

全矩阵约 120 局 × 120–180 s。runner 支持 `--worlds/--cases/--seeds` 子集筛选：日常迭代跑子集，阶段门槛跑全量（可借 `--domain-start` 并行 2–3 个无头实例）。

### 5.2 基线挂架

控制器 `strategy` 参数切换 v31 / frontier / levy / 各阶段系统；所有策略跑完全相同的矩阵与 seed。

### 5.3 归因仪表

仿真侧有上帝视角（scenario 真值 + 真值占据栅格），每个真值源每局记录：是否进过 FOV、最小 FOV 距离、无遮挡可见时间窗（含信号强度）、被遮挡接近事件数、活跃期与可见窗重叠率（动态源）、tracker 状态轨迹（首检出 → confirm 延迟，或卡点）。

每局输出失败归因摘要，漏源自动分类为：**没走到 / 被挡住 / 到了没确认 / 时机错过**。矩阵层面汇总四类占比变化，作为各阶段门槛"X 类失败减少"的数据来源。

（运行时算法用的可见性掩码与归因仪表共用同一射线检测机制：前者不见真值、后者对照真值。）

### 5.4 指标与统计

- 核心：recall / precision / duplicate（沿用现有定义）；新增首确认时间、全源确认时间、动态源重捕获时间、清场概率校准、决策周期 CPU 耗时分布。
- 统计：每格 5 seed 报均值±标准差；"显著优于"用 Mann-Whitney U（p<0.05），跨场景合并用配对检验。
- 回归保护：宣称改进必须附全矩阵成绩，局部变好、其它变差不过门槛。
- 产物：每局一个 artifact 目录（CSV + 归因 JSON + 元数据），矩阵汇总 Markdown 报告，可直接进 devlog。

## 6. 风险与回退

1. **Nav2 在障碍世界不稳**（交接报告 §14.1 的已知问题会被放大）：阶段 0 扩展 `nav2_health_check.py` 验证；评测记录每局 Nav2 可用率；可达性检查可降级为直线无碰检查；直接 `/cmd_vel` 兜底保证实验不死。
2. **粒子滤波影子模式输给快层**：快层系统即完整交付物，PF 对比分析进论文，无沉没成本。
3. **算力超预算**：PF 降粒子数 / 降频 / likelihood 降采样三档退；分层结构保证慢层降级不伤主回路。
4. **仿真吞吐瓶颈**：子集迭代 + 门槛全量 + domain 隔离并行。
5. **为单一世界调常数的故态复萌**：新常数进 `params.yaml` 必须附跨世界矩阵数据；归因仪表使修哪一层有据可查。

## 7. 测试策略

- **TDD**：每个新模块先写纯 Python 单测。`visibility.py`：手工占据栅格验证射线边界情形（贴墙、斜射、FOV 跨墙角）；`residual.py`：合成场验证残差归零与单源遗漏检出；Kalman track：合成轨迹验证速度收敛与预测；`belief.py`：合成观测序列验证源数后验收敛；`clearance.py`：蒙特卡洛合成数据验证校准。
- 现有 34 个测试全程保持通过；矩阵 runner 加 30 秒冒烟 case 作接线回归。
- 单测保证"算的对"，仿真矩阵保证"用得好"；仿真验证只在单测全绿后进行。

日期：2026-09-06；目标登记规则更新于 2026-09-07。负责人要求先提交现状，再通过降低任务要求精简代码，同时保留对基础能力有帮助的改进。调整前检查点：`581c802`。

## 当前目标

巡检固定位置、持续发热的 2–5 个目标：采集热图，定位到地图，融合重复观测，绕开障碍和遮挡继续探索，输出源位置、强度、置信度与观测年龄。保留 A 级理想观测、B 级前视热表面观测和 UGV/radiometric 接口。

目标移动、熄灭/重现、速度估计、交叉身份连续、自动判断是否搜完不属于当前能力。任务由操作者或外部时间/路线预算停止；停止不表示证明无漏源。

## 删除的代码

- `clearance.py`：搜完概率、概率历史更新和校准工具；删除控制器计算、发布话题、参数、采集器订阅和验证依赖。
- `revisit.py`：预测位置重访队列、冷却/公平调度及控制器入口。
- 四维常速运动模型：用二维 `position_filter.py` 替代；删除速度外推、速度衰减、速度协方差、运动扩展门控和重捕获计数。
- 慢层运动状态、按速度合并条件、运动/生灭事件日志及父子标签记录；候选确认和未确认候选清理统一由快层负责。
- 场景线性/圆周/航点/随机运动、发热开关调度、热源强度变化模型和 Gazebo 实体移动服务调用；删除六个动态场景，三源软件契约场景改为静态。加载旧动态 YAML 明确报错。
- 控制器按预设源数、长时间没发现新源而宣称完成的分支和对应参数。
- `phase1_gate.py` 旧论文验收门禁及其专用测试；矩阵运行器保留静态场景、真值匹配、缓存验证和性能统计，不再要求清场输出。

## 保留的共享能力

| 能力 | 保留理由 |
|---|---|
| Kalman 位置平滑、协方差与归一化关联、实测位置门控 | 抑制定位抖动，避免旧标签抢占别的热点 |
| 多帧确认、跨视角关联、去重 | 静态物体也会产生重复观测 |
| 观测新鲜度、同时间戳防重计数、未确认候选清理 | 不把陈旧热点、噪声或遮挡解释成可靠新证据 |
| B 级透视、深度、遮挡、噪声、发射率 | 静态巡检仍需要贴近真实热相机的观测 |
| 预处理、标定与 TF、深度配准、地图融合 | 热图定位与真实硬件输入的基础 |
| 相机扫描、换视角、残差探索、可达性、受阻换点与失败点冷却 | 帮助发现遮挡或尚未看到的静态目标 |
| 慢层位置、强度/尺度、不确定性、源数后验与选点 | 保留静态估计能力及 online/shadow/off 对照；收益仍需实测 |
| GP-UCB、快层和原静态策略 | 保留可运行基线，检验复杂模块是否帮助基础能力 |

缺测期间源位置保持不变，位置不确定性随时间增加以容纳建图/配准漂移。已确认热源的 ID 和确认状态在同一运行会话内保留；缺测仅增加观测年龄与定位不确定性，不衰减存在置信度、不退役或重新确认。雷达前方安全间距 `forward_clearance` 是避障保护，与删除的“搜完概率”不同，必须保留。

## 配置与接口

不增加任务覆盖文件或 `task_params` 开关。主配置仍为 `params.yaml`、`multisource.yaml`，UGV 使用 `ugv_thermal.yaml`。默认 `dual + online`，可显式选择 `fast` 或 `gp_ucb`。

跟踪参数 `motion_model` 改为 `estimator_model`（legacy/kalman）；常速过程噪声改为 `position_noise_std`。快层使用 `candidate_timeout_s` 清理未确认候选。慢层删除独立出生、确认、剪枝和合并参数，按 `/thermal/sources` 的统一 ID 更新属性和参与规划。旧参数文件需要同步更新。

`SourceEstimate` 删除 velocity、velocity_variance、reacquisitions、last_reacquisition_s；保留 age_s、位置协方差及静态估计字段。升级后重新构建接口和所有依赖。旧派生消息 bag 不保证兼容，优先回放原始观测。

## 验证与剩余问题

验证分为算法回归、ROS 接口/UGV 合成输入、静态 Gazebo 真值匹配。删除取消要求的测试，同时增加静态噪声平滑、遮挡期间不漂移、遮挡后标签连续、五源渐进可见和拒绝旧动态配置的回归。

范围精简不自动修复历史 A 级覆盖不足或 B 级重复 ID。逐例记录发现数、定位误差、重复标签和实际移动，不以节点运行 PASS 代替探测达标。不执行动态全矩阵、概率校准和论文显著性门槛。

实机 radiometric、标定、深度和 TF 条件不变；Lepton/PT3 本身不提供深度。Pi 5 负载和真实设备表现仍需实机验证。本次结果见 [精简验证记录](../../devlog/2026-09-06-static-inspection-simplification.md)。

目标管理：候选过滤 → 唯一登记 → 属性更新 → 待处理/已处理。慢层不得创建第二套永久身份，控制器不得因观测过期丢弃已知静态位置。两个位置接近的已确认 ID 不自动合并；合并尺度限制、误确认不自动撤销、重启不持久化须在验证报告中明确。

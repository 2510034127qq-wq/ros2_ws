## 完成要求

- [ ] 快层：常速 Kalman、预测关联、动态去重、重捕获记录、预测重访及探索仲裁。
- [ ] 慢层：默认 Rao-Blackwell 源簇（运动条件高斯、强度/尺度估计、Bernoulli 存在概率和源数分布），残差 birth、可见性条件 death、merge/split/association、影子/在线/关闭、超时及异常回退。
- [ ] 规划：残差与后验信息收益、可达性、重访、慢层先验校正；保持快层独立可运行。
- [ ] 清场：显式空间/幅值/漏检模型、扇区和动态历史、快慢版本；校准输出与明确未校准状态。
- [ ] B 级：三维盒/柱热表面、前视透视射线、遮挡/自遮挡、深度、噪声/偏移/emissivity；运行时算法不读取仿真热源真值。
- [ ] 观测：时间/坐标系/完整外参/测量类型、热图与深度定位、A/B 可切换；局部控制取消固定 64x48 和地面像素距离假设。
- [ ] 硬件软件接口：UGV 启动接线、真实 radiometric 温度输入及录包回放路径；仅声明软件支持，不声明实机已验证。
- [ ] GP-UCB 强基线可运行；保留原策略，提供小规模对比与消融入口。
- [ ] 纯算法测试、ROS 构建、代表性 A/B 闭环、慢层关闭/异常回退、运行耗时、输出数据与图表。
- [ ] 用户文档、迁移说明、需求逐项证据审计与任务提交。

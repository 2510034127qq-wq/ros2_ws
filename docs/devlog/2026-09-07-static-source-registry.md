## 当前结构

- `SourceTrackerCore` 是唯一身份入口。候选连续多帧、存在置信度和定位协方差达到条件后登记为 confirmed；只有未确认候选超过 `candidate_timeout_s` 无观测才删除。
- 已确认静态目标在同一运行会话中保留 ID、位置和确认状态。不因离开视野、冷画面或较长时间缺测衰减存在置信度，不退役、不重新确认。位置协方差允许建图漂移，`age_s` 表示真实观测年龄。
- 删除 cold/stale/suppressed 生命周期、重复记忆过期、确认历史标志、冷证据时间缓存、双份更新/合并/晋升/抑制流程。legacy 的检测方式、平滑更新和宽排斥范围保留，但与 Kalman 共用静态登记流程；历史基线结果不能当成相同算法版本。
- 新候选先检查是否位于已知目标附近，避免相同热表面的分裂观测再建已确认身份；保留有距离限制的一对一关联和归一化匹配。
- 慢层接收 `/thermal/sources`，按原 ID 更新位置高斯、强度/尺度。删除独立提取候选、残差新生、独立 ID、空间重新关联、确认、衰减、剪枝和合并。A 级地图拟合、B 级表面属性更新、属性不确定性、事务预算、online/shadow/off 和规划信息收益保留。
- 慢层的置信度/确认状态由登记层提供。`cardinality_pmf` 是已登记假设的 Bernoulli 卷积，不是全场景未知源数的独立后验。位置回馈按相同 ID 做保守协方差交集，不再按最近位置二次配对。
- 控制器直接使用登记位置和稳定 ID 的已处理集合；不因观测过期丢掉已知源，已确认源可作为待访问位置。候选的接近仍检查新鲜度；导航避障、超时和失败点冷却不变。

## 范围限制

身份和已处理记录在进程内保存，重启开启新会话，不提供跨重启持久化。确认前过滤仍可能误确认；已登记目标不会自动撤销，熄灭不会被解释为目标删除。这是当前静态持续热源任务约定，不是动态跟踪能力。

Kalman 默认 `merge_radius_m=1.0`，相邻真实热源小于合并尺度时仍可能难分；没有用无限大的去重半径掩盖重复问题。静态登记改进不等于全矩阵、复杂场景覆盖或 Pi 5 实机验收通过。

# B 级小目标与温度范围默认值

修改前基线：6853c84。目标是减小默认物体和温差，并允许用户指定目标表面温度范围；未改变探测算法或引入压力测试中的额外噪声、缺测、标定误差。

- 默认目标宽 0.3 m、高 0.8 m，主配置、节点缺省、热表面生成与 Gazebo 实体生成保持一致。
- `sensor_node.ros__parameters.source_temperature_range_c` 默认 `[28.0, 37.0]`，为绝对摄氏温度；默认 22℃ 环境对应 6–15℃ 温升。
- 每个源按 ID 与运行种子独立均匀抽取一次，持续恒温。相同种子与 ID 可复现，源列表顺序不影响结果。run_seed 为 0 时沿用节点 random_seed 作为温度种子。
- 省略参数使用默认范围；下限等于上限可设置固定温度。要求两个有限浮点数、环境温度 < 下限 ≤ 上限。
- 范围作用于 B 级并覆盖场景的旧 amplitude；A 级保持原场景温升。成像和真值共享抽样后的源状态，真值 strength 仍为相对环境温升。图像读数受发射率和噪声影响，不保证全部像素位于表面设定温度范围内。
- 在 multisource.yaml 修改一行即可定制。复制完整配置并通过 software_params 指定时无需重建；修改源码配置后需重建 thermal_bringup。README 已提供示例。

## 验证

- pytest：195 项通过。覆盖范围、可复现性、恒温、固定端点、非法范围拒绝、成像与源状态一致、Gazebo 实体尺寸一致。
- thermal_sensor_sim / thermal_bringup 构建成功；48 对源/安装文件一致。
- 实际 ROS 节点：省略范围、自定义 `[32.0,34.0]`、固定 `[35.0,35.0]` 三例，每例收到 24 帧真值，均满足范围与恒温检查。
- 主启动 B 五源障碍场，种子 202，60 秒采集：发现 4/5，漏掉 S3_southeast；匹配定位 P95 0.160 m，重复时间格 0、身份切换 0、未匹配新鲜确认记录 0；行驶 7.01 m。无运行崩溃，物理实体中心与真值最大偏差为 0。这是配置/集成验证，不代表完整探测验收，也不与先前 180 秒结果直接作优劣比较。

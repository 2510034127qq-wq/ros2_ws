# 冗余复审与删除

基线：`efffa87`。本轮按“确认无效再删除”处理运行负担与维护负担，不把缺少消融证据等同于算法没有收益。

## 已删除、合并

- 删除主启动中的 `smoother_server`、`waypoint_follower`、`velocity_smoother`，同步删除生命周期登记、依赖与配置。当前行为树只使用规划、跟随、清图与等待；底盘原来直接消费 `/cmd_vel`，未消费速度平滑器输出。保留的节点与速度链继续按原路径工作。
- BT 只加载当前 XML 使用的六个插件；恢复服务只加载实际调用的 Wait。删除没有启动入口的 Map Server/Saver 配置。SLAM 自身的保存功能不受影响。
- 着色节点与 RViz 使用同一启动条件。无界面运行从 21 个 launch 子进程降到 17 个；包含短暂的生成机器人命令，不表示 17 个永久 ROS 节点。
- 删除控制器仅写入/清空、从未读取的温度窗口及 `peak_window_s` 参数。现代巡检分支跳过旧梯度幅值排序和温度统计，旧基线继续使用原计算。
- B 慢层在构造地图数组之前识别表面观测，跳过只供 A 高斯场拟合使用的数据转换。
- 三个静态规划器共用地图收益公式，两个规划器共用热源概率公式；保留候选生成、权重和选择规则。删除上游已经不再产生的 `suppressed/stale` 目标状态分支，并同步测试描述。
- 删除梯度节点无效 `frame_id` 参数、探测脚本的未读字段和绘图脚本未调用的 `safe_div`。删除没有算法选择作用的 `reconstruction_method` 参数；消息/服务仍如实输出 `direct_linear`。

不含测试、验证文档，代码与配置新增 42 行、删除 168 行，净减少 126 行。没有新建运行模式或通用调度框架。

## 保留与复审边界

慢层、B 级观测、GP-UCB、原静态基线保留。场重建与梯度节点仍为当前控制/采集/诊断接口提供数据，不能整包认定为死代码。深度、TF、遮挡、重复观测合并、观测新鲜度与直行避障保护仍支持静态探测。

上轮发现的 launch 参数覆盖、绘图脚本场景真值硬编码，以及旧/新控制流程耦合仍存在。前两项属于配置/结果正确性修正，后一项需要进一步改变模块边界；本次没有通过大规模改写或取消已有能力来处理，也不宣称所有复杂度已经清空。

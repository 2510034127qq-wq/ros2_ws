# 静态热源巡检代码精简

调整前已按用户要求提交所有已有项目资料：`581c802 docs: checkpoint project notes before simplifying inspection scope`。本轮按用户补充明确以减少代码为目标，撤回新增任务覆盖开关的方案，改为删除专用实现。

## 改动

删除搜完概率、预测重访、动态场景生成/实体移动、运动状态外推、重捕获统计和旧论文门禁。源估计和慢层改为二维位置；保留归一化关联、实测位置门控、确认/去重、当前观测反证、相机扫描、可达性/绕障、失败点冷却、残差探索、B 级观测与慢层静态后验。

同时删除全部自动完成分支，包括老策略按指定源数或无新源超时结束的规则。控制器持续巡检，由外部预算或操作者停止。前向雷达安全距离 `forward_clearance` 保留，它不是清场概率。

六个动态 YAML 删除，软件契约三源场景改为固定持续发热。旧动态输入明确报错。矩阵脚本保留静态 2/3/5 源与不同障碍布局；`phase0` 名称保留为命令兼容，其网格已变为 4×3，不能与历史 4×6 当作同一实验。

`SourceEstimate` 移除速度与重捕获字段；更新全部发布/订阅端和配置，重新构建接口及七个运行包。清理增量 install 中遗留的已删除模块/动态 YAML。历史实现与旧派生消息需使用 `581c802`；当前消息定义不保证与旧 bag 兼容。

## 闭环实测

使用固定场景和 seed，Gazebo 串行运行。每项发现数按物理源匹配（1 米门限、新鲜确认 age≤1.5 秒、至少 3 次命中）计算，采样窗口不包括启动预热期。

| 用例 | 策略 | 采样时间 | 结果 |
|---|---|---|---|
| B 双源、open、seed 101 | dual/online | 90 秒 | 2/2，0 重复消息，0 串 ID，定位 P95 0.243 米，实际移动 10.37 米 |
| B 五源、obstacles、seed 202 | dual/online | 90 秒 | 5/5，0 重复消息，0 串 ID，定位 P95 0.392 米，实际移动 7.63 米；4440 个物理实体位置核对，最大误差 0 米 |
| A 双源、open、seed 303 | fast/shadow | 90 秒 | 运行链路通过，探测仅 1/2；定位 P95 0.274 米，实际移动 11.87 米，覆盖不足保留 |
| UGV 合成输入 | 估计，运动关闭 | 18 秒 | 通过；单个 confirmed 源 |

双源慢层 compute P99 1.60 ms、快层最大更新 1.266 ms、规划最大 11.5 ms；仅代表当前主机短时运行，不能推定 Pi 5 性能。

## 保留的失败与证据边界

第一次精简后 B 双源运行中，节点持续正常，但采样工具因误删覆盖计数初始化而异常退出，未生成探测结果。修复为 `max_observed_cells` 后重跑成功；失败日志保留在 `bags/software_validation/20260906_static_simplified_b2/`，不算通过用例。

首次 B 五源障碍用例（120 秒）发现 5/5 源，0 同时重复消息，但 S4/S5 各有两个先后确认 ID；定位 P95 0.433 米。逐实体服务没有返回几何样本，因此整体 probe 失败。改用 Gazebo `/thermal_scene/model_states` 同时核对静态实体后，90 秒重跑通过；并用合成 ROS 消息验证位置一致、位置错位、实体缺失三种情况。此次修改仅影响验证器，不修改机器人算法。原 120 秒负面结果保留在 `20260906_static_simplified_b5_obstacles`；90 秒结果为 `20260906_static_simplified_b5_retry`。窗口和轨迹不同，不能宣称修改验证方式解决了 ID 问题。

本轮此前仅关闭开关的试跑在 `20260906_static_scope_b`，其结果不作为删除代码后的证据。精简双源重跑为 `20260906_static_simplified_b2_retry`，硬件契约为 `20260906_static_simplified_hardware`。根目录均为 `bags/software_validation/`，原始证据不提交 Git。

范围变化与短时通过不代表历史漏检/重复 ID 已全部解决，也不证明已搜完或慢层优于快层。没有运行动态全矩阵、论文显著性、清场校准或物理设备/Pi 5 测试。

汇总数据和原始证据摘要的 SHA-256 见 [静态巡检验证快照](../software/static_inspection_validation.json)。A 级输出在 `bags/software_validation/20260906_static_simplified_a2_fast/`。源码和日志均不支持“全部场景已无漏检/无重复”的结论。

# 接手文档 03 · 控制器状态机详解

核对日期：2026-09-14。代码：`thermal_motion_controller/thermal_motion_controller/controller_node.py`。

## 先判断走哪条控制路径

`_timer_cb()` 更新位姿后首先分流：**sensor_model 不是 a，或 strategy 是 fast/dual/gp_ucb，都会调用 `_surface_timer()` 并返回**。因此默认 A + dual 也不是旧 FINE 梯度状态机；B + full 同样走世界坐标接近路径，不过其估计/选点配置仍可能采用旧策略。

仅 A + `full/frontier/levy/residual` 继续执行后面的旧 FSM。日志里的 CONVERGE/COARSE_SURVEY 名称可被现代分支复用，不能只凭状态名称断定执行了旧算法。

## 默认静态巡检路径

1. **处理已发出的接近导航。** 距中间点小于 0.5 m、接近超时（默认 20 秒）或 action 结束时撤销当前导航；未实际到达则把该源延期 20 秒。到达中间点后继续接近，不直接登记“已处理”。
2. **取得可访问目标。** 过滤已处理/冷却中的 ID；confirmed 可以使用历史登记位置，candidate 仍要求新鲜观测（默认 1.5 秒），并要求存在概率大于 0.5。
3. **B 级扫视。** 起步和已经开始的整周扫视要完成；之后有可执行源时先接近，没有目标时才按位移 4 m 或间隔 60 秒触发扫视。累计里程计转角判定一周，不用固定转动秒数猜测。
4. **保持目标并接近。** 默认保持当前 ID，另一个源的距离加停距仍小于当前距离才切换。先朝向目标，角度误差大于 0.5 rad 时不前进。接近线速默认不超过 0.2 m/s。
5. **受阻处理。** 直接控制立即执行地图/雷达保护，持续受阻不足 0.5 秒只停；超过后用 `surface_approach_waypoint()` 找已知空闲、车体足迹安全的停靠/中间点。局部推进受默认 2 m 步长限制，并须减少距目标距离；无可行点就延期继续探索。
6. **接近确认。** 估计距离不超过 `surface_standoff_m + 0.2`（默认 1.4 m），朝向误差小于 0.25 rad，停留至少 1 秒且源状态 confirmed，才加入 `_surface_seen_ids` 并输出 `[SURFACE_CONFIRMED]`。
7. **无待访问源时探索。** 正常保留探索航点；0.6 m 内算到达，45 秒超时或连续 12 秒无有效位移会重选。失败点附近 2 m 暂缓 45 秒。没有可行点时原地观察，不盲发远距离随机目标。

源登记确认与接近确认分属 tracker/controller；上述接近条件使用估计位姿，严格物理到达还需要独立真值核查。所有已知 ID 处理后仍探索，源登记与已处理集合仅存在于当前进程。

## 规划与慢层

`fast/dual` 使用热地图、残差/未知覆盖和旅行/转向代价；`gp_ucb` 使用有界 GP 选点。`planning.py` 实现候选评分，`runtime_policy.py` 管理扫视、探索保持、可行接近点与慢层准入。

`dual` 仅接收 online、ready、时间合法且未过期的后验。超预算、错误、off/shadow 或陈旧输出走快层。tracker 的慢先验按同 ID 做保守协方差交集，不允许慢层另建身份。`cardinality_pmf` 不是终止条件。

## 保留的 A 级旧状态机

| 状态 | 职责 |
|---|---|
| ASCENT | 局部梯度上升 |
| CONVERGE | 向峰值收敛，检查转入采样条件 |
| SAMPLE | 连续温升/热点与登记证据检查 |
| AT_PEAK | 确认后的短暂停留 |
| RELOCATE | 离开已知源邻域 |
| DEPARTURE | 确认后离场推进 |
| ESCAPE | 脱困与源排斥 |
| FRONTIER_NAV | 前沿导航，必要时直接控制 |
| COARSE_SURVEY | 粗探索航点执行 |
| SURVEY_PAUSE | 粗探索中的停顿观察 |

当前定义共 10 个热控制状态，Nav2 的 idle/pending/active/done 是另一组 action 状态。`target_selection.py`/`navigation_policy.py` 保留这条路线的策略与看门狗支持；`ThermalBeliefMap` 是控制器内部的旧覆盖表示，不是慢层 `BeliefState`。

## 运动保护与诊断

`_direct_guarded_cmd()` 对直接线速度检查雷达新鲜度、前方间距和地图通路；Nav2 命令由 Nav2 自己的控制/代价地图处理，这个函数不是所有 `/cmd_vel` 发布者的全局安全过滤器。Nav2 暂时不能接管时，直接回退也必须通过保护；因此“有回退”不等于永远不会停住。

现代接近已去掉两处重复的 4 秒距离进展判定，仍保留 Nav2 自身进度检查、接近时限、探索重选。默认 Nav2 goal/planner 容差为 0.25 m；热源停距 1.2 m 是另一种距离，不能互换。

优先看 `[SURFACE_TARGET]`、`[SURFACE_APPROACH_NAV2]`、`[SURFACE_APPROACH_DEFERRED]`、`[SURFACE_CONFIRMED]`、`[CAMERA_SWEEP]`、`[EXPLORE_RETARGET]`、`[SOFTWARE_HEALTH]`，并结合轨迹与地图。策略超时大量使用单调墙钟，ROS use_sim_time 不会把这些全部换成仿真秒。

已知边界：局部安全推进不是全局最优巡检路线；地图未知/障碍仍可能导致延期；A 双源短测仍不稳定；误确认不会自动撤销。现有测试不能证明任意场景下无碰撞或全部搜齐。

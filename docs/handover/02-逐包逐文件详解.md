## 包 3：thermal_sensor_sim（热相机仿真）

### `thermal_sensor_sim/sensor_node.py`（215 行，v13）
仿真热相机。每 0.1s（10Hz）：
1. 订阅 `/odom` 得到机器人 odom 位姿，算出世界位姿 `world = spawn + odom`。
2. `_world_field_at_sensor(t)`：把 64×48 像素网格按相机 FOV（默认 4m×3m）和当前 yaw 旋转投影到世界坐标，对每个**当前活跃**的热源叠加二维高斯，再加高斯噪声（noise_std=0.5℃）。
3. 发 `/sim/thermal_raw`（32FC1 图像）。
4. 发 `/sim/thermal_sources_truth`（所有源的真值，含活跃/非活跃状态）——**只给评测**。

关键参数（`params.yaml` 里 `sensor_node`）：`image_width/height=64/48`、`ambient_temp=22`、`noise_std=0.5`、`num_sources=3`（仅当 `scenario_file` 为空、用内置 Config-B 时限制源数）、`scenario_file/scenario_seed/scenario_jitter_std_m`。

> 重要：当传了 `scenario_file`，会加载 YAML 里**全部**源，`num_sources` 不再裁剪。

### `thermal_sensor_sim/scenario.py`（300 行，无 ROS 依赖）
热源场景的数据模型与 YAML 加载，是仿真“真值世界”的定义。

- `SPAWN_X/Y=(-6,0)`、`SENSOR_FOV_X/Y=(4,3)` 默认常量。
- `DynamicHeatSource`：一个源，支持多种运动 `motion`：`static`/`linear`/`circular`/`sinusoidal`/`waypoint_loop`/`random_walk`/`appear_disappear`，以及强度漂移（线性 + 正弦）和 `active_schedule`（出现/熄灭时间表）。
  - `position(t)` / `strength_at(t)` / `is_active(t)` / `state(t)` 算某时刻的源状态。
- `ThermalScenario`：spawn + FOV + 源列表；`active_states(t)`（仅活跃）/`all_states(t)`（全部，含非活跃，给真值）。
- `default_config_b_scenario(n)`：内置 Config-B 3 源（SA_left/SB_far/SC_weak）。
- `load_scenario_file(path)`：解析 scenario YAML（`config/scenarios/*.yaml`）。
- `apply_run_seed(scenario, seed, jitter_std_m)`：用 seed 给每个源加确定性位置/幅值扰动（多 seed 实验复现用）。

> 这是“评测多样性”的来源：9 个 scenario YAML × 6 个 world = 多种测试组合。

### `thermal_sensor_sim/colorizer_node.py`（86 行）
把 `/sim/thermal_raw`（32FC1）按 inferno 色图映射成 `/sim/thermal_colorized`（rgb8），**纯粹给 RViz 看，不参与决策**。clamp 范围 `t_min=22, t_max=65`。订阅用 BEST_EFFORT（与 sensor 匹配）。

## 包 4：signal_preprocessor（滤波）

### `signal_preprocessor/preprocessor_node.py`（249 行，v2）
对 `/sim/thermal_raw` 做**时序滤波 + 空间平滑**，输出 `/thermal/filtered`。
- 时序：`kalman`（默认）/`moving_avg`/`exp_smooth`，逐像素一维卡尔曼。**v2 关键修复**：原来 R=0.25、Q=0.01 导致卡尔曼增益≈1（等于不滤波），改成 Q=0.08、R=4.0（K≈0.02，强平滑）。
- 空间：3×3 高斯卷积（纯 numpy `_conv2d_valid`，edge padding），sigma=0.8 像素，让梯度计算更稳。
- 每 100 帧打印一次 SNR 对比日志（`[FILTER_STATS]`）验证滤波效果。

## 包 5：thermal_field_reconstructor（重建 + 世界热图 + 可见性 + 残差）

这是 phase1 改动最集中的包。6 个文件：

### `grid_geometry.py`（5 行）
共享几何常数：`GRID_CENTER_X=-6.0, GRID_CENTER_Y=0.0, GRID_SIZE_M=50.0`。**单一来源**，被在线热图和离线真值栅格共用。

### `observation.py`（83 行，phase1 观测契约）
定义**可替换的观测接口**，为将来真实前视热相机预留：
- `SensorPose2D`（x/y/yaw/frame_id）、`ThermalObservation`（带 stamp、pose、measurement_type、采样点世界坐标、温度、置信度，构造时校验数组长度一致）。
- `MEASUREMENT_FIELD_DIRECT`（仿真俯视直读场温）/ `MEASUREMENT_SURFACE_RADIANCE`（真实表面辐射）两种测量类型。
- `project_pixels_to_world(...)`：把矩形俯视 FOV 投影到世界坐标。
- `TopDownRectProjector`：A 级仿真用的理想俯视矩形投影器，`project(image, pose, t)` → `ThermalObservation`。
> 设计意图：算法只消费 `WorldThermalGrid`，俯视矩形和将来的前视透视视锥都是同一契约的实例。

### `visibility.py`（75 行，phase1 可见性，无 ROS）
对占据栅格做**射线检测**：
- `OccupancyView` / `from_flat(...)`：把展平的占据数据包成可查询视图（阈值默认 65，未知/越界算空闲）。
- `occupied_at(view, wx, wy)`：向量化查询某些世界点是否被占据。
- `visible_mask(view, ox, oy, txs, tys)`：从机器人 `(ox,oy)` 到一批目标点，逐点判断中间是否穿墙（沿线步进 0.1m）。返回每个目标是否可见。
- `line_reachable(view, x0,y0,x1,y1)`：单条直线可达性（规划层降级用）。

### `residual.py`（31 行，phase1 残差）
- `predict_field(...)`：给定已知源 `(x,y,amp,sigma)` 列表，在世界网格上正向预测温度场（环境温 + 高斯叠加）。
- `residual_field(measured, predicted, view_state)`：`max(0, 实测 − 预测)`，且**只在 `view_state==VIEW_CLEAR`（看清）的格保留**，其余清零。残差大 = 可能有未发现的源。

### `thermal_mapping.py`（186 行，核心数据结构 WorldThermalGrid）
把每帧热图像融合进**世界坐标系大网格**（默认 50m×50m，0.25m/格 → 200×200）。
- 状态量：`mean`（增量均值）、`_m2`（Welford 在线方差）、`visit_count`、`last_seen`、`blocked_count`、`view_sectors`（8 方位位掩码）。
- `integrate_observation(obs, occupancy)`：核心融合。把观测点落格 → 对每个被观测格做**可见性射线检测**（占据栅格存在时）→ 可见格用 Welford 增量更新均值/方差/访问数/时间戳/方位扇区；被挡格只累加 `blocked_count`。
- `integrate_image(image, robot pose, ...)`：便捷封装（内部用 TopDownRectProjector）。
- `snapshot(now_s)` → `GridSnapshot`：导出供发布。计算每格 `confidence`（随访问数饱和、随时间 `age_decay_s=45s` 衰减）、`view_state`（NEVER=0/BLOCKED_ONLY=1/CLEAR=2）。
- 视图三态常量：`VIEW_NEVER/VIEW_BLOCKED_ONLY/VIEW_CLEAR`、`N_VIEW_SECTORS=8`。

### `reconstructor_node.py`（134 行，ROS 节点）
订阅 `/thermal/filtered`，输出 `/thermal/field`（ThermalField）+ service `/thermal/get_field_info`。
- 主要是把图像整理成 ThermalField 消息 + 算 min/max/mean/std。
- `_hotspots(arr, mean)`：在 `mean + hotspot_min_temp_delta`（默认 4℃）阈值之上做 NMS（非极大值抑制，`hotspot_min_distance=5` 像素），取前 5 个热点，confidence 按“高出阈值的程度”归一化。
> 注意：reconstructor 退出时直接 `rclpy.shutdown()`，与其它节点的 `try_shutdown()` 风格不一致（已知小问题，见 `06`）。

### `thermal_mapper_node.py`（212 行，ROS 节点）
把感知图像融合成世界热图 `/thermal/map`（5Hz）。
- 订阅 `/thermal/filtered`（图像）、`/odom`（位姿）、`/map`（SLAM 占据栅格，用于可见性）。
- `pose_source=odom`（默认）：`world = spawn + odom`；`pose_source=tf` 时用 `map→base_link` TF。
- `_slam_map_cb`：把 SLAM 地图原点加 `spawn` 偏移，构造 `OccupancyView` 供射线检测。
- 每帧 `integrate_observation`，按 `publish_rate` 限频发布 ThermalMap。
- 每 100 帧打印 `[FUSE]` 日志（耗时 ms、看清格数、被挡格数）。

## 包 6：thermal_gradient_processor（梯度）

### `thermal_gradient_processor/gradient_node.py`（130 行，v2）
订阅 `/thermal/field`，输出 `/thermal/gradient`。
- `_sobel`（默认）/ `_central_diff`：纯 numpy 算 gx/gy（Sobel 核归一化除 8）。
- 按 `subsample_stride=4` 降采样，逐点打包成 `Gradient`，组成 `GradientArray`。
- **v2 关键修复**：`peak_temperature_celsius` 报 `arr.max()`（视野内最热像素温度），不再报“最大梯度像素”的温度——后者在羽流边缘（离中心约 σ），曾导致控制器在离源 3~4m 就误判“到了”。`peak_pixel_x/y` 也改成最热像素位置。

## 包 7：thermal_motion_controller（源跟踪 + 决策大脑）

5 个文件，含项目最复杂代码。控制器主体见 `03`，这里给其余文件 + 概述。

### `source_tracking.py`（338 行，无 ROS，核心算法）
`SourceTrackerCore`：从世界热图峰检测 → 最近邻多假设跟踪 → 候选/确认/去重。
- `extract_detections(...)`：从 `temperature_mean + confidence` 网格中找局部极大热峰（`>= ambient + min_temp_rise` 且 `confidence >= min_confidence`，3×3 局部极大），按强度×置信度×新鲜度排序，按 `merge_radius_m` 去近邻。`max_detection_age_s=8s` 限制只用新鲜格（动态源关键）。
- `update(detections, now)`：最近邻关联（马氏门 `gate_m=1.25`）→ 更新已有 track 或新建；无观测的 track 概率按 `stale_decay_s` 衰减、超 `stale_after_s` 转 stale；然后 `_merge_close_tracks` 合并、`_promote_confirmed` 确认、`_suppress_duplicates` 去重。
- 确认条件：`existence_probability>=0.75` 且 `observations>=5` 且 `consecutive_observations>=5` 且协方差够小。
- 去重记忆：确认源 `duplicate_memory_s=60s` 内阻止附近重新出生候选，避免重复确认（precision 杀手）。
- track 状态：candidate / confirmed / stale / suppressed。

### `source_tracker_node.py`（139 行，ROS 节点）
薄封装：订阅 `/thermal/map`，调 `SourceTrackerCore.update_from_map`，发 `/thermal/sources`。新确认源打 `[SOURCE_CONFIRMED]` 日志。参数全在 `params.yaml` 的 `source_tracker_node`。

### `clearance.py`（73 行，无 ROS，phase1 清场概率）
**生成式**清场概率 v1：
- `ClearanceParams`：源空间率 `source_rate_per_m2`、每扇区探测率 `p_detect_per_sector=0.7`、残差阈值、epsilon、域半径。
- `cell_miss_prob(...)`：每格漏检概率 = `(1 - p_detect)^k`（k=该格被看过的有效方位扇区数，上限 4）；残差超阈的格强制 miss=1（说明那有信号没解释）。
- `clearance_probability(...)`：把漏检概率在自由空间上积分成泊松强度 λ，返回 `exp(-λ)` = “域内无未发现源”的概率。
- `reliability_curve` / `expected_calibration_error`：可靠性曲线 + ECE，用于验收“宣称概率是否校准”。

### `planning.py`（507 行，无 ROS，规划打分核）
世界热图上的**信息增益/覆盖/残差**目标选择函数（纯函数，吃 numpy 网格，吐目标点）：
- `PlannerWeights`：各项权重（信息增益 1.0、源概率 1.4、覆盖 0.7、旅行代价 0.45、重复惩罚 1.2、风险 0.2）。
- `select_information_gain_target(...)`：逐格打分（信息增益 = 未见度+方差+年龄；+源概率高斯；+覆盖=1/(1+访问)；−旅行代价−重复−风险−可加方向偏置），返回最高分格。
- `select_coverage_ring_target(...)`：**环形足迹扫掠**——不是选单格，而是评估“下一个相机视场足迹落哪最划算”，可绕已确认源、惩罚最近走过的方向、可限制角度扇区/锚点。
- `select_exploration_sector_yaw(...)`：从地图证据选一个**探索方向（yaw）**，黄金角 phase 只做平局打破。
- `select_residual_target(...)`：phase1 残差探索目标（残差质量+未见+被挡+年龄−旅行−重复），可带直线可达性筛选。

### `target_selection.py`（922 行，无 ROS，目标策略层）
`SourceSeekTargetSelector`：控制器的**“去哪”策略大脑**（控制器自己只管“怎么走/状态切换”）。封装上面 planning.py 的函数，按任务上下文选目标：
- `select_frontier` / `select_levy_jump` / `select_coarse_waypoint` / `select_departure` / `select_escape_yaw`。
- 复杂的多源扇区扫掠逻辑：`_single_source_expansion_target`（单源后扇形展开）、`_source_set_expansion_target`（多源后沿源对横向/缺口/向外扇区扫掠）、`_best_departure_ring`。
- 输入 `SourceSeekContext`（机器人位姿、已确认源、tracker 源、热图、belief_map 等），输出 `StrategyTarget`（目标点 + reason + 执行偏好 nav2_preferred/direct_first）。
> 这一层在 commit `3878f53` 从控制器里抽出来，目的是“任务策略”和“运动执行”解耦。

### `controller_node.py`（2303 行，v31，最大文件）
决策大脑。11 状态 FSM + Nav2 集成 + 直接 cmd_vel 兜底 + belief map。**详见 `03`**。

```
└── ...
```

配置要点（`nav2_params.yaml`）：
- 控制器 `RegulatedPurePursuitController`（差速专用，弯道自动减速），巡航 0.22m/s。
- 规划 `NavfnPlanner` + A*，`allow_unknown=true`（允许穿未建图区，热搜索必须）。
- `xy_goal_tolerance=1.5m`（热导航不要厘米级精度）。
- global_costmap 用 **rolling_window 60×60** + 只 obstacle+inflation 层（**故意去掉 static 层**，因为 SLAM 早期小地图会把机器人挤出界——见 `06` 已知问题）。

配置要点（`slam_params.yaml`）：online_async 建图，分辨率 0.05，最大测距 12m，`transform_publish_period=0.02`（50Hz TF），`map_update_interval=5s`。

Python 包的 `setup.py` 注册 console_scripts，`setup.cfg` 指定 ROS lib 安装目录，`resource/<包名>` 是 ament 标记，`package.xml` 声明依赖；`__init__.py` 标记模块包。新增运行依赖或入口时须同步这些文件。

## thermal_interfaces

`CMakeLists.txt` 注册 8 个 msg 与 1 个 srv，必须先于消费者构建。

| 文件 | 含义 |
|---|---|
| `ThermalPoint.msg` | 单个图像热点、温度和置信度 |
| `ThermalField.msg` | 图像标量场、分辨率、统计量与热点数组 |
| `Gradient.msg` / `GradientArray.msg` | 单点/数组梯度、峰值、实际图像宽高 |
| `ThermalMap.msg` | 世界热栅格及观测年龄/可见状态 |
| `SourceEstimate.msg` / `SourceEstimateArray.msg` | 静态源 ID、candidate/confirmed、位置协方差、属性与 age_s |
| `BeliefState.msg` | 登记源后验、cardinality_pmf、health/mode/compute_ms/revision |
| `GetFieldInfo.srv` | 查询最新场摘要，可请求完整数组 |

接口已删除速度/重捕获以及清场消息和未消费的视角历史字段。更新派生消息消费者后重新构建；旧派生 bag 不保证兼容。

## thermal_bringup

| 文件/目录 | 作用 |
|---|---|
| `launch/sim_nav_slam_launch.py` | 主仿真：Gazebo、模型、SLAM/Nav2、A/B 热链路与可选 GUI |
| `launch/ugv_thermal_launch.py` | 外部 UGV 的热处理覆盖层，默认关闭运动 |
| `config/params.yaml` | 基础热链路与保留旧控制参数 |
| `config/multisource.yaml` | B 热表面、小目标温度、快慢层和静态接近/探索覆盖 |
| `config/ugv_thermal.yaml` | 真实输入单位/帧、TF 位姿、深度与硬件速度配置 |
| `config/config_b_sources.yaml` | 默认三个固定源的布局，不等于 sensor_model=b |
| `config/scenarios/` | static_two_sources、static_five_sources、static_offset_sources、software_contract_multisource 四个 YAML |
| `config/nav2_params.yaml` | Nav2 控制/规划、costmap 与恢复配置 |
| `config/slam_params.yaml` | SLAM Toolbox 参数 |
| `config/navigate_to_pose_simple.xml` | 由 launch 注入的 Nav2 行为树 |
| `rviz/thermal_nav_slam.rviz` | 当前 RViz 配置 |
| `worlds/` | nav、obstacle_field、corridor_rooms、mixed_rooms、zigzag_corridors、sparse_islands 六个 world |
| `worlds/occupancy/` | 各 world 的评测占据缓存，不是 SLAM 在线地图 |
| `CMakeLists.txt` / `package.xml` | 安装资源与声明启动依赖 |

修改源码配置须重建 thermal_bringup；自定义软件层和硬件层分别用 software_params/hardware_params 指定。主 launch 的内联值仍可覆盖 YAML。

## g1_description

`urdf/g1_nav.urdf` 是当前差速仿真模型，包含雷达和世界位姿 odom 配置。`g1_thermal.urdf.xacro`、`g1_29dof_rev_1_0_with_inspire_hand_FTP.urdf` 及 meshes 是保留 G1 资产；主 launch 不使用其完整人形动力学。CMake/package.xml 负责安装与包依赖。

## 明确暴露的问题

1. **A 级延长运行仍漏源。** 180 秒实际行驶约 23.19 米，仍只发现 T1_north，未发现 T2_east。日志显示接近东南方向后又切回已知源重访；搜索覆盖与重访仲裁值得优先检查。该机制解释是日志诊断，尚未通过隔离实验确认因果。
2. **单源多标签仍存在。** 直线 seed 202 的 L2_cross、航点用例的 W1_waypoint、五源用例的 P4_circular_north、障碍五源的 P1_waypoint 分别出现多个已确认标签。种子 202 有 8 条源消息同时报告同一物理源的两个 confirmed ID。因此，上轮单次短跑的身份稳定结论不能推广到更长运行或其他种子。
3. **转弯/随机运动存在位置异常。** 航点/随机用例有 7/213 条新鲜确认记录无法在 1 米内匹配真值；已匹配样本 p95 约 0.608 米。需同时关注异常记录和成功匹配误差。
4. **障碍生灭的有效重捕获不稳定。** 150 秒窗口只有效发现 2/3；A2_intermittent 启动阶段曾确认，但采样开始时已熄灭，其 11 条新鲜确认记录均匹配到熄灭体，后续活跃周期没有满足有效发现条件。不能解释成整局从未看到它，也不能把预热期日志算作持续探测成功。
5. **熄灭滞后仍未消除。** 普通五源、障碍生灭、障碍五源分别有 10、11、3 条新鲜确认记录匹配到熄灭物体。这是相关记录条数，不是独立误报事件率；若熄灭发生在采样前，无法从本窗口估计完整退确认延迟。

## 运行稳定性与范围

8 个用例均通过话题持续输出、实际运动、慢层健康、B 级深度与物体几何同步等检查，无运行节点崩溃。快层更新最大 3.354 ms、规划最大 31.7 ms；各用例慢层 p99 的最大值约 4.90 ms。Nav2 停滞回退仍有发生，运行通过不代表导航或探测性能门槛全部通过。

本轮没有重复构建未修改的运行包，也未把此前 188 项纯 Python 测试算作新增测试。未进行全量矩阵、统计显著性、完整 precision/recall、实机或 Pi 5 性能验收。

建议后续修复顺序：单源重复出生/关联与重确认；A 级搜索覆盖和重访仲裁；间歇源活跃周期的再探测与冷证据退确认。上述修复本轮未实施，避免改变固定版本测试结论。

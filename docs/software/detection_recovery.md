# 探测能力修复与缩减验证（2026-09-05）

本轮按“可以减少验证”的授权，修复前一轮审查发现的串 ID、熄灭轨迹滞留和探索漏源。保留快慢层、A/B 观测与 GP-UCB，不重跑全矩阵、全套基线/消融或论文统计门槛。本轮不是对原总体规划逐项全部完成的重新声明。

## 修复的原因与行为

1. **旧轨迹抢占新观测。** 原关联只比较 Mahalanobis 距离，旧轨迹协方差越大，匹配分数反而越有利。现在加入高斯似然的协方差归一化项，并约束相对最后实测位置的关联范围。短遮挡保留常速外推；超过 5 秒后速度按 2 秒时间常数衰减，避免表面质心误差持续漂移。强度差异和一对一关联继续保留。慢层先验只校正当前仍有观测支持的已确认快层轨迹。
2. **没有利用冷观测反证旧源。** 现在只用确实新看到的冷中心及邻域降低存在概率；邻域仍有热支持、没有观测、观测过期或被遮挡时不加这项惩罚。重复缓存帧不重复提供死亡证据。强反证后的再次发热需要重新确认。低概率旧源不再占用重访；过期预测位置不再大范围排除探索或扣除热残差。
3. **探索目标未到就频繁更换。** 正常行进时保持目标，按 0.6 米到达半径判断；45 秒超时或连续 12 秒没有有效位移时重选，失败点附近 2 米暂缓 45 秒。选点加入转向代价，同等未知区域优先减少转向，明显热证据仍可覆盖该偏好。
4. **地图未准备好就随机远行。** 新策略不再把缺少有效热地图/可行目标当作长距离随机目标的触发条件，而是等待、转向观察后重试。新控制器的最小选点距离使用实际到达半径，默认 1.5 米，不再受旧状态机约 2.5 米到达阈值限制。
5. **B 级只看行进方向。** 启动、位移达到 4 米或距上次扫描完成 60 秒后，进行一周相机转向扫描；使用里程计累计转角确认完成。扫描与移动均保留原有命令出口，线速度的雷达保护继续生效。

相关参数位于 `src/thermal_robot/thermal_bringup/config/multisource.yaml`。原策略入口保留；本轮探索行为主要作用于 `fast/dual/gp_ucb`，其中 GP 仍使用自己的选点核。

## 检查与结果口径

- 188 项纯 Python 检查通过，耗时约 30 秒，其中新增 15 项探测恢复检查。包括旧轨迹抢观测、长时间漂移、交叉运动和短遮挡兼容、冷/未知/过期/残留热支持区分、缓存帧、扫描转角、目标保持/受阻冷却、转向代价与离线评测口径。
- 新增 B 级贯穿检查实际调用热表面渲染、深度投影、3 秒热图融合和跟踪。在相同场景中，持续观测到的熄灭体降低存在概率，遮挡体仅按普通生存项衰减。
- 两个受影响 ROS 包 `thermal_motion_controller`、`thermal_bringup` 构建通过；56 对源码/install 文件一致。接口未改动，未重复构建所有无关包。
- 三类代表场景进行短跑迭代，失败/中间运行保留。最终结果及旧结果的统一重算保存在 [detection_validation_snapshot.json](detection_validation_snapshot.json)。原始 ROS 日志、图像、源轨迹与真值位于快照列出的 `bags/software_validation/` 目录。

`evaluate_detection_tracks.py` 只用于离线评测，不进入控制节点。统计限制为：采样窗口内、观测年龄不超过 1.5 秒、状态 confirmed、距离物理真值不超过 1 米、与次近源至少有 0.2 米距离差；至少三次有效命中才算发现一个活跃物理源。串 ID 使用物理身份，包含暂时熄灭但物体还在的源。多个标签数量本身不等于多个源被发现。

|---|---:|---:|---:|---:|

这是相同场景和采样时长的工程前后诊断，不是多 seed 配对统计实验。运行启动/调度时序不同，probe 在预热后开始，预热期间已经发现又失去视野的源可能不计入窗口发现数。各运行的源码指纹与输入配置单独保存；A 结果来自最后一次参数显式配置整理之前，默认数值未变。

最终 B 动态轨迹为 `src_1 → L2_cross`、`src_2 → L1_slow_east`、`src_3 → L3_drift`；北侧源不再像中间版本那样反复获得新标签。障碍生灭场景为 `src_1 → A2_intermittent`、`src_2 → A1_persistent`、`src_3 → A3_late`，原来 `src_1` 从 A2 串到 A1 的现象在这次复测中未出现。

生灭场景新鲜 confirmed 记录匹配到熄灭物体的次数为 8，旧运行是 12；这是记录条数，不是独立事件发生率。定位 p95 并未普遍改善，不以发现源数量增加替代精度结论。

最终 B 动态：快层更新最大 2.034 ms，规划最大 10.7 ms，慢层 p99 约 2.44 ms；本机数据不能当作 Pi 5 实测。三类新结果均无运行节点崩溃，Nav2 停滞回退仍有发生。


## 仍然存在的边界

- A 级静态双源短跑仍有一个未找到，不能声称探索漏源已全面解决。B 级有限用例的发现数也不代表任意障碍布局、任意时间窗口都能找到全部源。
- 生灭场景仍有熄灭后短暂的热图融合与确认滞后；未观测区域无法立即判定熄灭。没有把这个滞后改写成“零误报”。
- 长遮挡采用衰减运动假设，牺牲了长时间盲区中持续高速移动的精确外推；无法保证所有长遮挡重捕获都保留原 ID。
- 最近表面投影/栅格位置不等于物体中心。定位误差按当前用例报告，不声明精度普遍提高。
- 未测 Pi 5 性能、真实相机和 UGV；未完成全矩阵、统计显著性、清场概率校准或全任务 precision/recall 验收。
- 原规划中慢层三档自适应降级、B 级完整归因工具、FINE 状态机设计偏差等不属于本轮已解决内容，见更新后的 [原交付审计](software_completion_audit.md)。
